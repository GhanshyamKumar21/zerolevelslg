# Zero Level, Siliguri - website (GitHub Pages)
Upload ALL files and folders to the repo root, including hidden `.nojekyll` and `CNAME`.
Folder `assets/` must contain `zerobot.js` (chatbot). Styling is built into every page, so pages look right even without it.
Settings > Pages > Deploy from branch main / root. Custom domain: www.zerolevelslg.com. Enforce HTTPS.
Add your `logo.png` to the repo root. Submit `sitemap.xml` in Search Console.
Edit reviews in `index.html` (section "What students say"). Edit ZeroBot answers in `assets/zerobot.js`.
